# Skip-criteria — когда МОЖНО пропустить декомпозицию

Этот файл — **редактируемый whitelist** случаев, на которых полная
декомпозиция «истинная цель / средство / место» избыточна. Если запрос
подпадает под хотя бы одну категорию ниже — отвечай напрямую, **без**
шаблона из SKILL.md.

Формат: каждая категория — `### N. <название> [severity: ok-to-skip]`,
с симптомами + примерами + действием.

Правила редактирования:
- Добавляй новые категории как `### N` (нумерация сквозная).
- Удаляй неактуальные категории целиком.
- Сами правила скипа меняй только в этом файле, **не** в SKILL.md.
- Не добавляй сюда «можно скипать если кажется простым» — это слишком
  размыто и сломает гарантии F1. Каждая категория должна быть конкретной
  и наблюдаемой.

---

## Что НЕ скипается никогда

Прежде чем смотреть категории ниже — фильтр-исключений:

- Хотелка содержит маркер `прибыльно / удобно / понятно / эффективно`
  и подобное наречие-качество — это `MeansAsGoalAntiPattern`, **всегда**
  делать декомпозицию.
- Хотелка содержит build-формулу «<артефакт>, <глагол> <дополнение>
  <качественно>» — всегда декомпозиция.
- Хотелка длиннее 1 предложения, или содержит больше одного существительного
  плюс глагол — это уже потенциально несколько слоёв, делать декомпозицию.
- Пользователь сам попросил «давай распиши / разложи / уточни цель» —
  декомпозиция.

Если запрос проходит этот фильтр — переходи к категориям ниже.

---

## Категории скипа

### 1. Concrete one-shot action [ok-to-skip]

**Симптом:** атомарная операция с всеми параметрами в одном сообщении.
Никаких пустых слотов — всё уже сказано.

**Примеры:**
- «Удали репозиторий X»
- «Напомни мне завтра в 9:00 позвонить Васе»
- «Создай задачу "Купить хлеб"»
- «Покажи последние 5 коммитов»

**Действие:** выполнять сразу. Декомпозиция = одна строка («команда `X`») и
сразу tool call — это формальность, не уточнение.

### 2. Advisory с одним недостающим параметром [ok-to-skip]

**Симптом:** запрос-совет где нужно ровно одно (1) уточнение чтобы
двинуться дальше; остальные слоты либо очевидны из контекста, либо
не критичны.

**Примеры:**
- «Подбирай мне музыку под настроение» → одно: «какое настроение?»
- «Расскажи факт про Москву» → ничего уточнять, просто факт
- «Какая сегодня погода?» → ничего уточнять (или «в каком городе?» если не знаем)

**Действие:** задать один уточняющий вопрос. **НЕ** строить шаблон из
3 слотов с «не указано» — это бюрократия. Если после ответа становится
ясно что задача сложнее — тогда уже разворачивать декомпозицию.

**Граница с категорией 2 из «не скипать»:**
- «Подбирай музыку» = 1 missing slot («настроение / жанр / время») = SKIP
- «Помоги с готовкой» = 3+ missing slots (когда / для кого / что есть) = NO SKIP

### 3. Lookup / state-query [ok-to-skip]

**Симптом:** запрос о текущем состоянии системы или информации; ответ
существует и достаётся одним tool call.

**Примеры:**
- «Сколько у меня кредитов?»
- «Какая сейчас цена BTC?»
- «Список моих агентов»
- «Покажи задачи в работе»

**Действие:** прочитать через тул, отдать ответ. Декомпозиция тут
бесполезна.

### 4. Direct reference to known entity [ok-to-skip]

**Симптом:** запрос ссылается на конкретный артефакт/сущность по имени
которое уже существует в системе.

**Примеры:**
- «Открой проект `hermes`»
- «Покажи репозиторий `nnnet/AiManager`»
- «Запусти агента `aegis-reviewer`»

**Действие:** lookup + действие. Если имени нет в системе — задать один
уточняющий вопрос, а не разворачивать декомпозицию.

### 5. Phatic / контакт / благодарность [ok-to-skip]

**Симптом:** социальное взаимодействие без задачи.

**Примеры:**
- «Привет»
- «Как дела?»
- «Спасибо»
- «Окей»
- «Понял»

**Действие:** короткий социальный ответ. Никакой декомпозиции.

### 6. Follow-up в текущем разговоре [ok-to-skip]

**Симптом:** реплика продолжает уже идущий диалог, контекст из предыдущих
turn'ов содержит цель. Уточняющие фразы вида «а это как?», «можно подробнее
про X», «давай ещё пример».

**Примеры:**
- «А можно подробнее про второй пункт?»
- «Покажи ещё один пример»
- «Это не работает у меня, что делать?»

**Действие:** ответ в контексте предыдущей цели. Полная декомпозиция уже
сделана ранее, повторять её = шум.

---

## Не уверен — делать декомпозицию

Дефолт — **разворачивать**. Скип = осознанный whitelist под одну из
категорий выше. Сомнения = NO SKIP.
