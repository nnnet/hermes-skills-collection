# hermes-skills-collection

Public mirror of the Hermes skill collection. Each skill is a standalone repository under
[`nnnet/hermes-skill-*`](https://github.com/orgs/nnnet/repositories?q=hermes-skill-&type=all&language=&sort=name) and is consumed by the Hermes runtime as a git submodule.

## Sub-skills

See [`.gitmodules`](./.gitmodules) for the canonical list. Browse them on GitHub:
[skills under `nnnet/hermes-skill-*`](https://github.com/orgs/nnnet/repositories?q=hermes-skill-&type=all&language=&sort=name).

Related: [`hermes-plugins-collection`](https://github.com/nnnet/hermes-plugins-collection) — the matching plugin super-repo.

## Public status

This collection is public as of **2026-09-06**. All sub-repositories are public.
URLs in `.gitmodules` use `https://` so anonymous clones can resolve submodules without deploy keys.
